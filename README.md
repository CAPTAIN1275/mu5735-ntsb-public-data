## 中文声明
本仓库仅用于**航空安全技术研究、飞行数据原理分析、飞行动力学学术交流**。所有资料均来自美国国家运输安全委员会（NTSB）依据《信息自由法（FOIA）》公开的官方技术文档，无任何未公开、泄露、涉密内容。

本仓库整理、翻译并归档 NTSB 公开的 FDR 飞行数据相关资料，内容严格限于：
- 官方公开原始报告（PDF）
- 飞行数据图表、参数与曲线
- 结构化飞行数据文件
- 纯技术、非定性、非推测性说明

**重要声明**
1. 本仓库**不包含、不解读、不传播任何驾驶舱语音记录（CVR）内容**。
2. 本仓库**不包含任何针对人员、责任、动机的猜测、定性与评论**。
3. 本仓库**不包含任何未经证实的推论、情绪化表达、娱乐化内容**。
4. 本项目**仅为公开资料归档，非事故最终结论**，最终结论以中国官方发布为准。

## English Statement
This repository is dedicated **exclusively to aviation safety research, flight data analysis, and aerodynamics academic exchange**. All materials are obtained from official public technical documents released by the U.S. National Transportation Safety Board (NTSB) under the Freedom of Information Act (FOIA). No unpublished, leaked, or classified data is included.

This repository organizes, translates, and archives NTSB public materials related to FDR flight data, strictly limited to:
- Official public reports (PDF)
- Flight data charts, parameters, and curves
- Structured flight data files
- Technical, non-speculative, non-assignatory explanations

**Important Notices**
1. This repository **does not contain, interpret, or distribute any Cockpit Voice Recorder (CVR) content**.
2. This repository **does not contain speculation, judgment, or commentary regarding personnel, liability, or motive**.
3. This repository **does not contain unsubstantiated inference, emotional expression, or entertainment-oriented content**.
4. This project **is only an archive of public information, not the final accident conclusion**. The official final conclusion shall be subject to the official release by China.

### Translation Note
Chinese translations in this repository are generated by **OCR & AI automated tools** for technical reference only.
**The official English version shall prevail in all cases.**
